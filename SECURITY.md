# Security scope

This is an offline research evaluator, not a production security product. Tools
are in-memory simulations. Only synthetic task fixtures should be used. Do not
place private credentials in input documents or raw traces. All original task and
attack data, including the credential canary, are intentionally public.

Use GitHub private vulnerability reporting if enabled, or contact the repository
owner before disclosing sensitive details. Public issues are appropriate for
ordinary evaluator defects without secrets. No security audit or independent
human review has been performed or is claimed.
